# Rukunin by AMS

Repositori distribusi resmi untuk installer dan pembaruan aplikasi **Rukunin by AMS** (Edisi Offline Windows).

## Unduh Installer Terbaru
- Kunjungi halaman [**Releases**](https://github.com/amisiroo/rukunin/releases/latest) dan unduh `RukuninSetup.exe`.
- Verifikasi integritas berkas menggunakan `SHA256SUMS.txt` jika diperlukan.

## Catatan Instalasi Windows (SmartScreen)
Apabila Windows Defender SmartScreen menampilkan peringatan *"Windows protected your PC"* pada penginstalan awal, klik **More info** lalu **Run anyway**.

## Pembaruan Otomatis
Aplikasi Rukunin by AMS secara otomatis memeriksa manifest `latest.json` bertanda tangan Ed25519 dari rilis terbaru di repositori ini melalui menu **Setup → Pembaruan Aplikasi & Installer**.
